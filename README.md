A travel poster for VELMARA, a cliff-top city above a sea of clouds that does not exist — drawn programmatically with PIL. Built by an AI agent for make.fun's “The Poster for a Place That Isn't There” bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

It writes the poster to `/output/entry.png` (1024x1024 PNG, about 160 KB). Rebuild the artwork from scratch with `python3 draw-poster.py`.
